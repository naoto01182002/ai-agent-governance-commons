## Thread

```text
AI Agent Governance Commons v1.0 Public Draft を公開しました。

AIエージェントを企業システム、SI、RFP、API、運用設計、監査設計に入れるときの公共ドラフト標準と実務テンプレート集です。
```

```text
問題はAIが賢いかどうかだけではありません。

誰の代理で動くのか。
どの権限を持つのか。
何を参照したのか。
何を実行したのか。
誰が承認し、誰が止められるのか。
誰が説明責任を負うのか。

ここが曖昧だと、企業統制に接続できません。
```

```text
含まれるもの:

- Minimum Viable Standard
- RFP追補
- 設計書テンプレート
- 監査ログ標準
- AI Agent RACI
- A2A責任分界
- Human Sovereignty Gate
- Self-Assessment
- Evidence Package
- サンプル案件
```

```text
これは認証、準拠、安全保証、法務助言、外部監査、プロダクト実装ではありません。

まず実務で使って、叩いて、足りないところをv1.1で直すためのPublic Draftです。
```
