# LinkedIn Announcement Draft: v1.0 Public Draft

AI Agent Governance Commons v1.0 Public Draft を公開しました。

AIエージェントを企業システムに導入する際、重要なのはモデル性能だけではありません。

誰の代理で動くのか。どの権限を持つのか。何を参照し、何を提案し、何を実行するのか。誰が承認し、誰が停止でき、事故時に誰が説明責任を負うのか。

これらをRFP、設計書、監査ログ、RACI、Self-Assessmentへ転記できなければ、AIエージェントは企業統制、委託先管理、監査、法務レビューに接続できません。

AI Agent Governance Commons v1.0 Public Draft は、そのための公共ドラフト標準と実務テンプレート集です。

含まれるもの:

- Minimum Viable Standard
- RFP追補テンプレート
- 設計書テンプレート
- 監査ログ標準
- AI Agent RACI
- A2A責任分界
- Human Sovereignty Gate
- Self-Assessment Checklist
- Evidence Package
- サンプル案件

これは認証、法的準拠、安全保証、外部監査、AIエージェント基盤の実装ではありません。

まずPublic Draftとして公開し、実務で使われた結果をv1.1へ反映していきます。

想定読者:

- 企業の情シス、IT企画、DX部門
- SIer、コンサルティング会社
- 内部監査、法務、リスク管理部門
- AIエージェントをRFP、設計、運用、監査へ入れようとしている方
