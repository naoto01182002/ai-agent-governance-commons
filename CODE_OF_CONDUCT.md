# Code of Conduct

AI Agent Governance Commons is intended to support practical, constructive discussion about AI agent governance standards.

This repository welcomes critical discussion, disagreement, and strong review of documents, templates, assumptions, and governance structures. It does not welcome harassment, personal attacks, discriminatory language, or bad-faith disruption.

## Expected Behavior

Participants are expected to:

- focus criticism on the artifact, not the person
- explain reasons when proposing changes
- respect that this repository is a public draft, not a certification body
- avoid implying that a person, vendor, product, or organization is certified, compliant, legally approved, or safe because of this repository
- keep discussions relevant to AI agent governance, RFPs, design, audit, RACI, self-assessment, and A2A responsibility boundaries

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- discriminatory or exclusionary language
- repeated off-topic arguments after maintainers ask to stop
- using this repository to promote unsupported certification, compliance, legal approval, or safety claims
- posting secrets, credentials, or private information

## Enforcement

Maintainers may edit, hide, close, lock, or delete issues, pull requests, comments, or discussions that violate this Code of Conduct.

Maintainers may also restrict participation when behavior repeatedly prevents constructive improvement of the repository.

## Scope

This Code of Conduct applies to GitHub issues, pull requests, discussions, and other contribution channels related to this repository.
