# Security Policy

AI Agent Governance Commons is primarily a public draft standard and practical template repository for AI agent governance.

This repository does not provide a runtime system, certification service, compliance judgment, legal advice, safety guarantee, or external audit.

## Scope

Please report issues if you find any of the following:

- leaked secrets, credentials, tokens, API keys, webhook URLs, or private connection information
- unsafe guidance that may encourage uncontrolled AI agent execution
- wording that may imply certification, compliance, legal approval, safety guarantee, or external audit
- defects in authority, audit log, approval, stop-right, rollback, RACI, or A2A responsibility-boundary guidance
- examples or templates that could cause misleading responsibility allocation, such as treating an AI agent as Accountable in RACI

## Not in Scope

The following are outside the scope of security handling for this repository:

- requests for legal advice
- vendor-specific product support
- certification requests
- individual system implementation support
- requests to judge whether a specific organization, product, or proposal is compliant

## Reporting

If the issue is not sensitive, please open a GitHub issue and use the most relevant issue template.

If the issue contains sensitive information, do not post it publicly. Contact the repository maintainer directly through an appropriate private channel.

When reporting, please include:

- affected file or section
- why the wording, example, or template may create risk
- suggested correction, if available
- whether the issue may affect RFP, design, audit, RACI, self-assessment, or A2A usage

## Handling Policy

Security and safety-related issues are prioritized in the following order:

1. leaked secret or credential exposure
2. wording that may imply certification, compliance, legal approval, safety guarantee, or external audit
3. unsafe authority, approval, stop-right, rollback, audit, or responsibility-boundary guidance
4. unclear wording that may cause practical governance misunderstanding

## Disclaimer

Using this repository, copying its templates, or referencing AI Agent Governance Commons does not mean that a system, vendor, proposal, organization, or AI agent is certified, compliant, safe, legally approved, externally audited, or fit for any particular purpose.
